# Calendrier de travail

تقويم عمل بسيط في ملف HTML واحد، يعمل مباشرة في المتصفح بدون أي مكتبات أو خادم.

## الميزات
- تبديل الأيام بلمسة، مع عدّاد للشهر وللسنة
- حفظ تلقائي على الجهاز + تصدير/استيراد نسخة احتياطية (JSON)
- التنقل بين الأشهر بالسحب أو الأسهم، وزر «Aujourd’hui»
- دعم الوضع الداكن وقارئات الشاشة ولوحة المفاتيح

## التشغيل
افتح `index.html` في المتصفح، أو انشره على GitHub Pages.

## النشر على GitHub Pages
1. Settings ← Pages
2. Source: **GitHub Actions** (أو Deploy from a branch ← `main` / root)
3. سيظهر الرابط: `https://USERNAME.github.io/calendrier-de-travail/`

## تطبيق PWA
التطبيق قابل للتثبيت ويعمل بدون إنترنت بعد أول زيارة (`manifest.json` + `sw.js`).
- **أندرويد/كروم:** قائمة ⋮ ← «تثبيت التطبيق».
- **آيفون/سفاري:** مشاركة ← «إضافة إلى الشاشة الرئيسية».
يتطلب HTTPS، وهو متوفر تلقائياً على GitHub Pages.
